01 / MENTAL MODELChange the route, keep the map.

A model has a lot
of weights.
Your task may not
need to change all of them.

LoRA freezes a pretrained weight matrix and learns an update through two smaller matrices.[1]

h = Wx + (α / r) BAx

For W ∈ ℝdout × din, choose A ∈ ℝr × din and B ∈ ℝdout × r. The rank of BA is at most r. The original W can still be full rank.

We train A and B, while gradients still flow through the frozen model. “Frozen” means no weight updates, not no computation.

A useful distinction
LoRA limits the update's rank. It does not prove that the pretrained model or the task itself is low rank.

This is a constructed linear-algebra experiment using a known orthonormal basis, not an LLM training run. Truncated SVD gives the best approximation in Frobenius norm.[2] Actual LoRA optimization does not have access to a target update or its SVD.

Explore the construction and its limits

We construct ΔW* = U diag(σ) Vᵀ using orthonormal discrete cosine bases. Reconstruction keeps the first r singular directions. Concentrated σ = [8, 4, 2, 1, .5, .25, .125, .0625]; distributed σ = [4, 4, 4, 4, 4, 4, 4, 4]. Factors can be B = Uᵣ√Σᵣ and A = √ΣᵣVᵣᵀ. Here the LoRA scale is 1. Parameter counts describe the factor representation, which stops saving parameters at r ≥ 4 for an 8 × 8 matrix.

PARAMETER BUDGET / ILLUSTRATIVE LLM

What does “efficient” buy?

Square projections of width 4,096, in 32 layers. Select adapted matrices per layer and rank. Counts exclude biases and any other trainable modules.

This is a parameter count, not a GPU memory or speed forecast. Frozen weights, activations, optimizer state, precision, sequence length, and kernels all matter. Real models may have non-square projections.

03A / WHAT IS ACTUALLY LEARNED?A task. Examples. An unseen test.

Learn an audience.
Not a single answer.

Your assignment: adapt a frozen caption scorer to a classroom audience. Train on examples, then check whether the learned correction transfers to captions it never saw.

THE INPUT

Four caption features

Detail, energy, formality, jargon. These are supplied numeric features, not text understood by a language model. Values run from −1 (low) to +1 (high).

THE TARGET

Two audience scores

Accessibility and appeal, in arbitrary centered units. Our invented audience favors detail and energy, and disfavors formality and jargon.

THE LEARNED CHANGE

A shared preference direction

A learns a combination of the four features. B learns how strongly that combination changes each output. W, the original scorer, stays fixed.[1]

This is a deliberately solvable teaching task. All examples and scores are synthetic. We authored an audience rule with an exactly rank-1 correction. Training never receives that rule: it gets only training inputs and target scores. This demonstrates learning a known pattern, not human preference modeling or measured LLM performance.

Instructor discussion: what would count as evidence?

A lower held-out error than the frozen baseline supports transfer within this constructed linear task. Low training error alone does not. With jargon fixed at zero, the data contain no information about its effect; more steps cannot supply the missing variation. The test set is intentionally visible for teaching. In a real experiment, repeatedly choosing settings from test results would contaminate the test: use validation data for iteration and reserve a final test.

For an LLM or diffusion model, replace these feature vectors and scores with the actual data, loss, and evaluations. Keep the same questions: what changed, which examples drove the change, and does it help on representative unseen cases?

Let e = h − y and z = Ax. With scale s, ∇Bℒ = se zᵀ and ∇Aℒ = sBᵀe xᵀ. Here s = 1.

Gradient for B

∇Bℒ = e · z

The input to B gates its learning signal.

Gradient for A

∇Aℒ = B · e · xᵀ

The current value of B gates this signal.

Through the frozen path

∇xℒ = (W + BA)ᵀe

Freezing W does not cut gradient flow to an earlier layer. Here x is fixed, so we do not update it.

SGD uses A ← A − η∇Aℒ and B ← B − η∇Bℒ simultaneously, with both gradients evaluated before either parameter changes. No momentum, weight decay, dropout, or quantization in this toy.

Why the initialization matters

With B = 0, ∇Aℒ = 0 initially, but ∇Bℒ can be nonzero when Ax and the output error are nonzero. After B moves, A can receive a gradient. If A = B = 0, both gradients remain zero under this SGD setup, even though the error is nonzero. The reverse initialization can also learn: nonzero B lets A move first. The original LoRA paper uses random A and zero B.[1] We use a fixed nonzero A for reproducible numbers, not a random draw.

Predict before clicking: which factor moves on step 1 in each initialization? On step 2? Why would an input with Ax = 0 change your first-step prediction?

What this teaches — and what it cannot establish
This is real gradient descent on a two-input, one-output linear regression toy. It isolates the chain rule; it is not an LLM or diffusion training run. Loss on one repeated sample is not evidence of generalization. Actual models use many adapted matrices, batches, nonlinear layers, and model-specific objectives.
04 / SAME TOOL, DIFFERENT OBJECTIVELoRA is an adaptation method, not a model family.

Language → images → beyond.

LoRA and QLoRA are different configurations. QLoRA combines low-rank adapters with a quantized frozen base and additional memory-saving techniques. LoRA alone does not imply a 4-bit base.[5]

01 / DISCOVER · 8 MIN

Find the breaking point.

In the rank lab, find the smallest rank capturing ≥95% energy for each target. Predict which requires more rank, then explain the difference without using the phrase “more is better.”

Instructor notes & solution

Concentrated: r = 3 (about 98.44%); r = 2 captures about 93.75%. Distributed: r = 8; r = 7 captures 87.5%. The singular-value spectrum determines how much energy each extra direction adds. Energy here is not validation accuracy.

02 / DESIGN · 12 MIN

Plan a defensible experiment.

Adapt a model to a new domain. Specify a baseline, held-out split, two ranks, target modules, fixed training budget, and measures of both task quality and unwanted behavior.

Instructor notes & discussion

Compare the frozen model with adapters under a controlled data and optimization setup. Split by source or subject to reduce leakage. Report seeds, learning rate, token budget, memory, and validation performance. Include general-domain regression checks. Equal steps do not necessarily mean equal compute; state what was held fixed.

03 / TRANSFER · 10 MIN

Change the model family.

Move your experiment from a causal LLM to a diffusion image model. What changes in the data, objective, evaluation, and safety checks? What stays the same?

Instructor notes & discussion

Low-rank factors and a frozen base remain. Diffusion commonly trains a timestep-conditioned denoising objective with image-caption data. Use held-out prompts, multiple seeds, and checks for fidelity, diversity, overfitting, and memorization. The exact objective and targets depend on the architecture and implementation.
